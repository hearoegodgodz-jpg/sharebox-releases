ShareBox 1.66.0 / Google 1.17.0 — сборка для проверки владельцем.

Мини-приложение Telegram включено в скрипт Google студии. Отдельная
публикация Netlify не требуется. Все участники группы аналитики получают
полный доступ; каждый запрос проверяет подпись Telegram и членство в группе.

Архив содержит встроенный Python и подходит для установки и обновления.
Проверены целостность ZIP, запуск, образ процесса, остановка, новая установка
и обновление установки без ShareBox.exe (с сохранением pythonw.exe).
Запуск проверен в Wine 10 под Linux, НЕ на настоящей Windows.
Онлайн-проверка CRL недоступна; подписи runtime, цепочки сертификатов,
временные метки и SHA-256 загрузок проверены.
Этот файл НЕ опубликован в канале автоматических обновлений.

Обновление:
1. Сделайте копию папки действующей установки.
2. ShareBox → Настройки → обновление → Выбрать архив… → этот ZIP.
3. В помощнике скачайте готовый Google-скрипт. Замените код в существующем
   Apps Script-проекте студии целиком и сохраните.
4. Начать развертывание / Развернуть → Управление развертываниями → активное
   веб-приложение → изменение настроек → Новая версия → Развернуть.
   Сохраните выполнение от владельца и доступ «Все». Ссылка /exec прежняя.
5. Дождитесь версии Google 1.17.0 в ShareBox. В группе аналитики отправьте
   /menu → Открыть помощника → личный диалог → Запустить → Открыть помощника.

Новый Google-проект не создавайте. Бота заново не добавляйте.
Привязки мастеров и выбранные чаты сохраняются в прежнем проекте.
